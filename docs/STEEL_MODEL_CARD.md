# Model card — steel fault type classifier (REAL public data)

Generated by `python -m scripts.steel_model`. Raw output: `docs/steel_eval.json`.

**Purpose:** show that the S4 method (LightGBM + TreeSHAP, baselines, held-out test) works on real manufacturing
inspection data, not only on the synthetic PCB generator. It is a separate reference model: it is not used on
PCB cases, and its data never enters a case or a Meta prompt (`data_origin=REAL` is blocked by the egress gate).

**Data:** Buscema, M., Terzi, S., & Tastle, W. (2010). Steel Plates Faults [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5J88N — CC BY 4.0. Modified: parsed and used to train/evaluate a classifier; no rows are redistributed.
Archive SHA-256 `cb8eb9859198b63f053e443513036b401746fa517ef58bd17c846c6741c93919` (100890 bytes, verified against the S1 record; the ZIP stays in git-ignored `data/`).
1941 plates, 27 numeric features, 7 fault types. **Every row is a faulty plate**, so the task is fault *type*
classification; it says nothing about detecting faulty vs good plates or about defect rates.

**Split:** stratified random 60/20/20, seed 11 (no timestamps or plate ids in the source). Train 1164, validation 388 (early stopping only), test 389.
The source has no plate or time ids, so rows from the same plate or period may sit on both sides of the split;
test scores may be optimistic for a new production period.
