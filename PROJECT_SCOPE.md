# Scope and provenance

- S0 began 2026-10-27 KST, after the conservative 02:00 KST boundary in the planning documents. Git timestamps are left untouched.
- This repository continues the S0 remote history with original S1 code. No pre-event source, commit, fixture, or result is imported.
- The parent workspace contains pre-existing planning documents. They inform the product direction but are not implementation evidence.
- S0 provides `/health`, a runnable SQLite/Alembic baseline, tests, CI configuration, and a separate optional LIVE Meta smoke command.
- S1 adds seeded synthetic PCB source tables, provenance and evidence storage, integrity checks, and case inspection APIs. UCI Steel Plates Faults is documented as an unimplemented adapter contract.
- Future S2–S7 features have not been implemented. Any public contest submission and official eligibility remain subject to organizer rules and user review.
